系统概述

Problem statement & solution class

问题：卒中、脊髓损伤、截肢、帕金森等神经功能障碍患者已超 1 亿；而键鼠屏幕的人机交互带宽仅约 25–40 bit/min，成为远程操控、危险环境作业等协同场景的瓶颈。

机会：电极阵列、边缘 AI 与解码技术同步成熟，使"读取意图—驱动执行—回传反馈"的闭环从实验室走向临床。

方案类：由 神经采集 → 边缘解码 → 机器执行 → 感觉反馈 → 云端 AI 构成的双向闭环系统，作为人体中枢与外周神经的外置延伸。

BRS · 业务需求规格说明

Business Requirements Specification — 表 4-1 框架

1. 简介

1.1 业务目的

抓住 BCI 从实验室走向医疗器械的窗口，在神经康复、人机协同、感知增强三个业务域形成可注册、可收费的产品线，建立"医疗 + 消费"双轮驱动的业务模型。

1.2 业务范围

  • 业务域：神经康复医疗（B2B2C）、特殊作业人机协同（B2B）、消费级增强设备（B2C）。
  • 范围内系统：植入 / 半植入 / 表面电极阵列、边缘解码盒、外部执行器、感觉反馈模块、云端训练与随访平台。
  • 范围外：纯诊断类脑电图设备、攻击性武器控制应用、纯算法授权（作为副产品）。

1.3 业务概况

内部五大子系统闭环耦合；外部实体包括医院康复科 / 神经外科、治疗师、NMPA / FDA、伦理委员会、医保商保、患者家属、云服务商与数据合规审计方。

1.4 定义

BCI 脑机接口 ECoG / 皮层脑电 EMG 肌电 闭环神经接口

1.5 主要相关方（业务管理层）

患者 / 残疾人、康复医师、神经外科医师、医院管理层、医疗器械监管机构、伦理委员会、医保 / 商保、企业研发与算法团队。

3. 业务管理需求

3.1 业务环境

  • 外部：老龄化与神经退行性疾病上升；国内外 BCI 管线推进；AI 提升解码率；按三类医疗器械从严审批；社会对"读脑"伦理高度敏感。
  • 内部：神经科学 + 嵌入式 + AI + 临床医学跨学科团队，须同时满足临床有效性与工程可靠性。

3.2 使命、目的与目标（SMART）

维度目标
使命让机器成为人体神经系统可插拔的"外置神经节"。
疗效目标卒中患者上肢 Fugl-Meyer 评分在 12 周训练后提升 ≥ 15 分。
带宽目标健康用户通过非侵入式设备达到 ≥ 100 bit/min 的有效信息输入。
注册目标3 年内取得首张 NMPA 三类医疗器械注册证。
安全目标严重不良事件率 < 1%，闭环中断可在 200 ms 内人工 / 自动断开。

3.3 业务模型

  • B2B2C：医院 / 康复中心按疗程收费（植入 + 训练包 + 随访订阅）。
  • B2B：为高危作业、科研机构提供定制化套件与算法授权。
  • B2C：消费级非侵入式头环 / 手环，主打专注力、运动辅助与无障碍输入。

3.4 信息环境

  • 神经数据按医疗数据等保三级 + 个人信息保护法双重合规，端到端加密。
  • 边缘侧实时推理 + 云端模型迭代；模型权重与原始信号分离管理。

4. 业务运行需求

4.1 业务过程（层次化）

P1 临床评估：影像、运动功能、认知评估，筛选适应证与禁忌证。
P2 方案定制：确定植入 / 佩戴位置、电极通道数与康复目标。
P3 植入 / 佩戴与校准：手术或门诊佩戴，3–4 周开机校准，采集个体化神经特征。
P4 闭环训练 / 作业：治疗师监督下进行康复训练或实际作业执行。
P5 反馈与调整：根据 MOE 指标调整解码参数与反馈强度。
P6 随访与退出：定期复诊、远程升级；达标或出现禁忌时安全退出。

4.2 业务运营策略与规则

  • R-01 意志优先：任何机器执行动作必须可被人体主观意志随时中止。
  • R-02 人在回路：康复模式下治疗师拥有最高参数调整权限。
  • R-03 数据最小化：只采集完成当前任务所必需的神经信号通道。

4.3 业务运行约束

  • 生物相容性满足 ISO 10993；植入物连续工作 ≥ 10 年。
  • 端到端信号延迟 < 100 ms（闭环感觉反馈 < 50 ms）；单次充电连续工作 ≥ 8 小时。

4.4 业务运行质量

  • 闭环系统可用度 ≥ 99.9%；意图解码准确率 ≥ 90%。
  • 患者使用满意度（ISO 9241-220）≥ 4.2 / 5；紧急断开机制 100% 可触发、可审计。

4.5 业务结构

设立医疗事业部（注册 + 临床）、消费电子事业部、神经 AI 研究院（算法 + 数据平台），与合作医院共建"神经康复联合实验室"。

ConOps · 运营概念（组织层）

Concept of Operations — 领导想如何运作这个业务

ConOps（组织 / 业务层）

回答"这家医院 / 公司未来打算怎么干"。

  • 合作三级医院在康复科设立"神经康复中心"，作为样板科室。
  • 患者入院 → MDT 会诊 → 定制植入 → 术后 4 周开机 → 每周 3 次闭环训练 → 出院居家设备 + 远程随访。
  • 消费级产品线进入数码渠道与无障碍公益项目。
  • 数据回流研究院，形成"临床—模型—硬件"飞轮。

OpsCon（系统 / 实物层，预告）

回答"这套设备具体怎么跑起来"，详见后文 StRS 第 6 节。

  • 电极采集神经电信号 → 边缘盒预处理 → AI 解码意图 → 驱动假肢 / 外骨骼 / 光标。
  • 执行动作同时经电刺激 / 振动回传触觉 / 位置感觉。
  • 任何环节人体可一键断开，回到原生神经通路。

5. 运行概念与生存周期

5.1 初步运行概念

  • 运行政策：医疗线按三类医疗器械管理；消费线按普通电子设备 + 知情同意。
  • 用户类型：患者（运动 / 认知障碍）、治疗师、植入医师、健康增强用户、运维工程师。
  • 支持环境：手术室、康复训练室、家庭、办公室 / 作业现场。

5.2 采办 · 部署 · 支持 · 弃置

  • 采办：医疗线医院招标 + 自研并行；消费线 DTC。
  • 部署：植入由合作医院完成；消费线用户自助佩戴。
  • 支持：远程 OTA + 48 小时现场响应。
  • 弃置：植入物可手术取出；设备按医疗电子废弃物回收；神经数据物理删除并出具证明。
  • 项目约束：首期预算 3000 万元，18 个月内完成注册临床。

StRS · 相关方需求规格说明

Stakeholder Requirements Specification — 表 4-5 框架

4. 系统运行需求

4.1 系统过程（闭环数据流）

① 采集：电极阵列以 ≥ 1 kHz 采样神经电信号（ECoG / EMG / EEG）。
② 预处理：边缘盒完成带通滤波、工频陷波、伪迹剔除。
③ 解码：轻量化 AI 模型在 50 ms 内输出运动意图类别 / 参数。
④ 映射与执行：意图映射为假肢关节角度、机械臂位姿或光标移动。
⑤ 感觉反馈：通过触觉电机 / 微电刺激回传压力、位置、温度。
⑥ 再采集：反馈信号改变下一帧神经活动，形成闭环。

4.2 系统运行策略与规则

  • 解码置信度低于阈值时，系统进入"保持姿态 + 提示治疗师"的安全状态。
  • 云端模型更新须在非训练时段推送，并可回滚。

4.3 系统运行约束

  • 闭环端到端延迟 < 100 ms；连续工作 ≥ 8 h；体温漂移不引起信号失真。
  • 断电时执行器自动锁止在当前安全姿态。

4.4 系统运行模式与状态

模式用途进入条件
校准模式采集个体化神经特征开机 / 佩戴后首次连接
康复训练模式治疗师监督下闭环训练门诊 / 康复室
自主增强模式患者 / 用户独立使用校准通过后
安全待机低功耗监测，不驱动执行器置信度低 / 用户疲劳
紧急断开切断机器通路，回到原生神经用户按键 / 医师触发 / 异常告警

5. 用户需求（按角色）

患者 / 用户（S1, S12）

  • 无需刻意学习即可"用意念"控制外部设备。
  • 植入 / 佩戴无明显异物感与热感。
  • 可随时查看康复进度数据。

医师 / 治疗师（S2, S4）

  • 实时看到解码置信度与异常信号告警。
  • 可按疗程调整训练强度与反馈增益。
  • 自动生成可导出的康复报告。

监管 / 伦理（S6, S7, S13）

  • 所有神经数据操作留存不可篡改日志 ≥ 10 年。
  • 硬件级"意志优先"开关，不可被软件绕过。
  • 用户可随时导出并要求删除全部个人神经数据。

工程师（S10, S11）

  • 设备健康状态远程可视，故障自动告警。
  • 算法 OTA 支持灰度发布与一键回滚。

6. 详细生存周期概念（OpsCon 展开）

6.1 运行概念

本系统是人体神经系统的可插拔外置层：不取代大脑与脊髓，只在外周和皮层之间搭桥。正常运行时神经信号被"读取—放大—翻译"成机器动作，再把机器侧感觉"翻译"回神经刺激；用户主动断开或检测到异常时，桥立即断开，人体回到原生状态。

6.2 采办 / 部署 / 支持 / 弃置

  • 采办：医疗线随医院康复设备招标；消费线电商直营。
  • 部署：植入式由神经外科在手术室完成；表面式用户门诊或居家自助佩戴。
  • 支持：7×12 远程客服，重大故障 48 h 上门。
  • 弃置：到期或患者要求时手术取出植入物；设备回收；神经数据出具删除证明。

典型运行场景

Operational scenarios

场景 S1 · 卒中后上肢闭环康复

入院：62 岁卒中后左侧上肢偏瘫患者入院，Fugl-Meyer 评分 28 分。
佩戴：上肢佩戴表面肌电 + 惯性单元，肘关节处加电刺激反馈。
训练：患者试图抓握水杯，系统采集残存肌电 → 解码意图 → 驱动外骨骼辅助抬手 → 指尖压力传感器回传触觉。
调整：治疗师看到解码置信度 0.82，适当减小助力，迫使患者多发力。
结果：12 周后 Fugl-Meyer 评分提升至 46 分，达到业务目标。

场景 S2 · 截肢患者智能假肢

残肢植入：28 岁前臂截肢患者接受肌电电极植入，4 周后开机。
日常：想"拿起杯子"→ 假肢手指在 80 ms 内合拢到合适力度 → 振动马达回传杯子重量。
安全：一次解码异常导致手突然松开，患者按下虎口物理按钮，假肢立刻锁止。

场景 S3 · 高危作业远程操控

作业：巡检员在干净控制室佩戴非侵入式头环 + 数据手套，远程辐射环境内的机械臂随其手部动作同步运动。
反馈：机械臂末端力传感器把阻力传回手套，操作员"感觉到"拧阀门的力度。
退出：换班时摘下设备，系统自动归档当班操作日志。
